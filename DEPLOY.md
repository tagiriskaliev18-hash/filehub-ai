# Руководство по развертыванию FileHub AI на бесплатном хостинге

Приложение полностью адаптировано для работы в облаке и раздачи единым сервером (бэкенд API + фронтенд интерфейс на одном порту).

Ниже представлены 2 основных способа:
1. **Облачный хостинг 24/7 (Render.com)** — постоянная ссылка вида `https://filehub-ai-xxxx.onrender.com`, работает всегда, компьютер можно выключать.
2. **Мгновенная ссылка прямо сейчас (Туннель)** — ссылка за 10 секунд без регистрации на хостингах, пока приложение запущено на вашем ПК.

---

## Вариант 1: Постоянный бесплатный хостинг 24/7 (Render.com)

**Render** — самый удобный бесплатный хостинг для Node.js и Docker без требования банковской карты.

### Шаг 1. Загрузите проект на GitHub
Если репозиторий еще не на GitHub:
1. Создайте новый репозиторий на [github.com](https://github.com/new) (например, `filehub-ai`).
2. В терминале в папке проекта выполните:
   ```bash
   git add .
   git commit -m "Prepare for free cloud hosting"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/filehub-ai.git
   git push -u origin main
   ```
*(Файлы `.env` с паролями и ключами автоматически исключены `.gitignore` и в репозиторий не попадут).*

### Шаг 2. Разверните на Render.com
1. Перейдите на [render.com](https://render.com) и войдите через свой GitHub-аккаунт.
2. Нажмите **New +** в верхнем правом углу и выберите **Blueprint** (или **Web Service**).
3. Выберите ваш репозиторий `filehub-ai`.
4. Render автоматически обнаружит файл `render.yaml` и настроит сервис:
   - **Name**: `filehub-ai`
   - **Runtime**: `Node` (или `Docker`, если используете `render.docker.yaml`)
   - **Build Command**: `npm install && npm run prisma:generate -w apps/api && npm run build`
   - **Start Command**: `npm run prisma:deploy -w apps/api && npm start`
5. Нажмите **Apply** (или **Create Web Service**).
6. Через 2-3 минуты сборка завершится, и вы получите готовую зеленую ссылку:
   ```
   https://filehub-ai-XXXX.onrender.com
   ```
   Эту ссылку можно отправлять кому угодно!

> [!NOTE]
> **Особенности бесплатного тарифа Render (Free Tier):**
> - **Спящий режим**: если к сайту никто не обращается более 15 минут, сервис «засыпает». При первом открытии ссылки после сна он «просыпается» за 30-45 секунд.
> - **Эфемерный диск**: на бесплатном тарифе Render перезапуск контейнера сбрасывает SQLite базу и папку `storage/`. Если в будущем понадобится постоянное сохранение данных для реальных клиентов, можно подключить Persistent Disk в Render Starter (~$7/мес) либо подключить бесплатную облачную БД (например, Neon Postgres).

## Вариант 2: Мгновенная ссылка прямо сейчас (Туннель)

Если нужно прямо сейчас скинуть ссылку человеку, пока ваш компьютер включен:

В папке проекта выполните:
```bash
npm run share
```
Эта команда запустит оптимизированный прод-сервер и откроет безопасный публичный HTTPS-туннель:
```
your url is: https://funny-otter-42.loca.lt
```
Просто скопируйте эту ссылку и отправьте человеку.

*(При первом переходе по ссылке localtunnel может попросить ввести публичный IP вашего ПК, который выводится на странице подтверждения).*

Альтернатива без паролей (Cloudflare Quick Tunnel):
```bash
cloudflared tunnel --url http://localhost:4000
```
Даст мгновенную ссылку вида `https://xxxx.trycloudflare.com` без каких-либо проверок IP.

## Переменные окружения (Environment Variables)

На Render в разделе **Environment** можно настроить:
- `JWT_SECRET` — генерируется автоматически через `render.yaml`.
- `ANTHROPIC_API_KEY` — (опционально) добавьте ваш ключ Anthropic (`sk-ant-...`), чтобы работал ИИ-ассистент в чате с файлами. Если ключ не указан, приложение работает в режиме деградации (файловый менеджер, конвертер и компрессор работают в полном объеме).
- `ALLOWED_CIDRS` — оставьте пустым для публичного доступа из любой точки мира.
